# Kayttojarjestelmat26

Tämä projektikokonaisuus on toteutettu osana LUT-yliopiston Käyttöjärjestelmät ja systeemiohjelmointi kurssia, toteutukselle 2025-2026.

Projektikokonaisuus koostuu kolmesta pienemmästä itsenäisestä projektista.
Projektit ovat saatavilla omissa kansioissaan tässä repositorissa. Jokainen projektikansio sisältää tarpeelliset ohjelmatiedostot sekä dokumentaation.

Tämä dokumentaatio on kooste projektikokonaisuuden etenemisestä.
